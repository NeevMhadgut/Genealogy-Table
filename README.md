# Genealogy-Table (Tauri + React Scaffold)

Lightweight Windows desktop app scaffold using Tauri (lightweight runtime) with React + Vite + Tailwind.

Run locally (prereqs: Node.js, Rust, cargo, tauri prerequisites - see https://tauri.app):

1. npm install
2. npm run dev        # run the frontend (Vite) at http://localhost:5173
3. In another terminal run `npm run tauri:dev` to start the Tauri dev app (or use `npx tauri dev`)

This branch contains an initial scaffold (frontend + tauri Rust backend) and a simple UI to create projects and people.
